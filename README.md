# create-graphic-novel

소설·에세이·시나리오를 그래픽노블/웹툰으로 각색하는 독립형 제작 스킬입니다.

- 표지 + 고정 페이지형, 세로 스크롤 웹툰, 페이지/컷별 이미지 생성 지원
- 기본 본문 8페이지 + 별도 표지 구조
- **생성 비율 옵션: 3:4 세로형 / 16:9 가로형**
  - 기본값: 3:4 portrait
  - 16:9: 시네마틱·프레젠테이션·영상 프레임·가로형 그래픽노블에 사용
  - 한 작업에서는 선택한 비율을 표지부터 본문까지 일관되게 유지
- 캐릭터·의상·소품·화풍 연속성 관리
- 페이지별 패널 구성과 이미지 생성 프롬프트 작성
- 한글 내레이션·말풍선·폰트 안전영역 설계
- 얼굴·신체·제스처·핵심 소품·상징·액션 등 핵심 요소 전체를 텍스트 금지영역으로 보호
- 내레이션·대사·제목·효과음·말풍선·꼬리 사이의 텍스트 겹침·잘림·충돌 원천 금지
- 일반 인물은 머리 1개·팔/손/다리/발 각 2개를 고정하고, 중복·누락·융합·분리·기형 인체를 자동 불합격 처리
- 텍스트 박스는 실제 문장량에 맞춰 크기·패딩·줄바꿈을 균형 조정
- 부분 수정 시 요청 영역만 교정하고 주변 연속성 재검수
- 모든 페이지를 원본 해상도와 최종 독서 크기로 이중 검수하고, 인체 기형·핵심 요소 가림·텍스트 겹침이 하나라도 있으면 수정 또는 재생성 후 재검수
- **4K급 마스터 기본값:** 3:4는 최소 3072×4096 px, 16:9는 최소 4096×2304 px
- **인쇄 기본값:** 최종 재단 크기 기준 300 ppi, 인쇄소 사양이 없을 때만 사방 3 mm 도련을 임시 적용
- PDF는 실제 재단·도련 크기로 만들고, 폰트를 포함하며, 300 ppi 미만 자동 다운샘플링과 저품질 JPEG 재압축을 금지
- 인쇄용 PDF와 용량을 줄인 화면용 PDF를 분리하며, 화면용 파일이 인쇄 마스터를 대체하지 않음
- PDF 저장 전후에 페이지 픽셀 크기·실물 크기·유효 ppi·도련·폰트 포함·다운샘플링 여부를 검수
- 특정 프로젝트나 이전 대화에 의존하지 않는 독립형 설계

비율은 제작 시작 전 `3:4 portrait` 또는 `16:9 landscape` 중 하나를 잠그고, 프롬프트·생성·조판·최종 QA까지 동일한 값을 사용합니다. 사용자가 비율을 지정하지 않으면 3:4를 기본값으로 사용합니다.

## 해상도·인쇄 품질 기준

PDF의 DPI 숫자만 바꿔도 화질은 늘지 않습니다. 생성 원본의 픽셀 수가 작거나, 작은 조판 캔버스에서 페이지를 만든 뒤 PDF로 저장하거나, 내보내기 과정에서 이미지를 다운샘플링·JPEG 재압축하면 최종 파일이 작고 흐려집니다.

다음 제작부터는 이미지 생성→확대(필요 시)→조판→PDF 내보내기 전 과정에서 위 4K급 마스터와 300 ppi 인쇄 기준을 잠급니다. 상세 계산식과 검수표는 [references/resolution-and-print.md](references/resolution-and-print.md)를 따릅니다.

## 결과물 저장 위치

- 앞으로 이 프로젝트에서 제작하는 모든 최종 결과물과 납품 패키지는 [Google Drive `graphic novel` folder](https://drive.google.com/drive/folders/1NZDZ_PIb_tcvbTliI5yof8dQ4g4-7puv)에 업로드합니다.
- 이미지, PDF, PPT, 문서, ZIP, 편집용 원본 등 사용자가 받을 최종 파일을 포함합니다.
- 임시 렌더, 캐시, 테스트 출력은 업로드 대상에서 제외합니다.
- 업로드 후 Google Drive의 파일 ID 또는 링크를 다시 확인한 뒤 작업 완료로 안내합니다.
- 사용자가 다른 저장 위치를 명시한 경우에는 최신 지시를 우선합니다.
