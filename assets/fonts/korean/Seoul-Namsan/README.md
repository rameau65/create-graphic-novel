## Usage and copyright guidance

Based on the Seoul Typeface licensing information supplied for this project:

- Anyone may download and use Seoul typefaces free of charge.
- Prohibited: sale, paid transfer, and unauthorized redistribution of the font files.

Official source:
https://www.seoul.go.kr/seoul/font.do

## Repository policy

Because unauthorized redistribution is prohibited, do **not** commit the Seoul Namsan TTF binaries to this public repository. Keep the official source URL and file mapping here and obtain the font from the official Seoul Metropolitan Government channel when needed.

Repository filenames should omit upload-copy suffixes such as `(1)`.

Family role: Korean sans / dialogue / clean body copy candidate.
