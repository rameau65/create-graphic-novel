Project source files:

- `경기천년바탕_REGULAR.TTF`

## Usage and copyright guidance

Based on the licensing information supplied for this project:

- Usage: video, print, web, logos, signage, and other uses are allowed.
- Commercial use: allowed without separate permission.
- Prohibited: selling or transferring the font files for a fee.
- Distribution/source: downloading from the official Gyeonggi Province channel is recommended.

Official source:
https://www.gg.go.kr/contents/contents.do?ciIdx=679&menuId=2457

## Repository policy

To avoid turning this repository into an unofficial font-distribution channel, keep the official download link and metadata here. Do not commit the binary TTF files to a public repository unless the official license is separately confirmed to permit redistribution through that repository.

Family role: Korean serif / literary narration / body copy candidate.
